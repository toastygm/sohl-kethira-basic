A module for the [Song of Heroic Lands](/sohl/) system
for Foundry VTT, carrying the basic mechanical pieces — skills, spells, sunsigns,
convocations and gods — needed to play in the world of Kethira.

## You will need the book

This module provides those pieces and none of the text that explains them, so it
cannot stand in for HârnMaster Kethira and is not usable without it. Buy the
hardback or the PDF from Keléstia:
[HârnMaster Kethira](https://www.kelestia.com/harnmaster).

## Installing

The module requires the
[Song of Heroic Lands](/sohl/) system for Foundry VTT.
Install it from Foundry's **Add-on Modules > Install Module** screen, using this
manifest URL:

```text
https://github.com/HeroicLands/sohl-kethira-basic/releases/latest/download/module.json
```

The source lives at
[HeroicLands/sohl-kethira-basic](https://github.com/HeroicLands/sohl-kethira-basic).
